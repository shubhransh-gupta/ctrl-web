What is CTRL+WEB?

CTRL+WEB is a collection of browser superpowers — not an AI chatbot. Each tool solves one annoying everyday task, locally, without an account.

  • Website — you're here. Learn what it does and how to install.
  • Extension — popup dashboard, right-click menu, and ⌘/Ctrl+Shift+K command palette.

v2.0 adds FindIT, Backtrack, Context, TabZero, CopyPaste, URLClean, WebTrash, and Deadline — plus the original utilities (Screenshot, Explain, Privacy, and more). Everything runs locally in IndexedDB and chrome.storage.

Primary entry points
  • Right-click → CTRL+WEB
  • Toolbar icon → quick actions
  • ⌘ Shift K → command palette

Install the extension

No Node.js. No npm. No terminal. Just download and load.

You need the pre-built zip, not the source code on GitHub. The zip contains compiled files Chrome can run.

Step-by-step (Chrome, Brave, or Edge)

  1. 1
    Download the extension

    Get ctrl-web-extension.zip from the latest GitHub Release.

    Download v2.0.0
  2. 2
    Unzip the file

    Extract to a folder you'll keep — e.g. ctrl-web-extension/. Don't delete it after installing; Chrome loads the extension from this folder.

  3. 3
    Open extensions page
    • Chrome → chrome://extensions
    • Brave → brave://extensions
    • Edge → edge://extensions
  4. 4
    Enable Developer mode

    Toggle Developer mode in the top-right corner of the extensions page.

  5. 5
    Load unpacked

    Click Load unpacked and select the unzipped folder (the one containing manifest.json).

  6. 6
    Start using CTRL+WEB

    Pin the extension icon, right-click any page, or press ⌘/Ctrl + Shift + K.

✓ This works

  • Download zip from Releases
  • Unzip and load that folder
  • Folder contains manifest.json + assets/

✗ This does not work

  • Cloning the GitHub repo and loading the root
  • Loading the src/ folder
  • Expecting "Download ZIP" of source to work as an extension
I'm a developer — build from source 
git clone https://github.com/shubhransh-gupta/ctrl-web.git
cd ctrl-web
npm install
npm run build

Then load the dist/ folder in chrome://extensions → Load unpacked.

Why isn't it on the Chrome Web Store?

CTRL+WEB is distributed as open-source releases for now. Install via the zip above — it's the same extension, just not listed in the store yet.

Do I need npm or Node.js?

No. End users only need the pre-built zip from Releases. npm is only for developers who want to modify the code.
